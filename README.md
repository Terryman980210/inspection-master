# 検査項目マスタ作成ツール 0.3.0

Python + ezdxf + PySide6 の2D DXF用デスクトップ試作版です。

## Windowsでの起動

Python 3.11または3.12（64-bit）をインストールし、ZIPを展開します。
`setup_windows.bat` を実行後、`run_windows.bat` で起動します。
デモは同梱の `demo_part.dxf` を開いてください。

## 操作

- DXFを開くとDIMENSION、寸法らしいTEXT/MTEXT、数値だけの文字を抽出します。
- 「候補一覧」の採用チェックをオンにすると「検査マスタ」の末尾へ移動します。
- チェックを外すと候補へ戻ります。測定器・備考は保持されます。
- 測定順は採用項目だけに付け、「上へ」「下へ」で変更できます。
- 測定器・備考はダブルクリックで編集します。
- CSV出力は採用項目だけ。UTF-8 BOM付きで出力します。

## 自動保存と復元

JSON保存ボタンはなくしました。採否・並べ替え・入力確定後に自動保存し、
画面右下に保存状態を表示します。編集は約0.6秒の待機後に保存されます。
終了時・別図面を開く前にも保存します。次回起動時は最後に開いたDXFと作業を復元します。
DXFを明示して起動した場合は、その図面を開きます。

図面ごとにフルパスと内容のSHA-256で作業を区別します。
図面内容が変更された場合は古い作業を適用せず新しい候補を抽出します。
ファイルを移動・改名した場合も別図面として扱います。元のDXFは変更しません。
作業データはユーザーごとのQt AppLocalDataLocation内の
`inspection-master/autosave` に保存されます（Windowsでは通常Local AppData配下）。
同じOSユーザー・同じ起動方法での継続利用を想定しています。
保存ファイルは一時ファイルを書いてから置換します。
保存失敗時は未保存表示になり、画面を閉じたり別図面に切り替えたりせず変更を保持します。
保存データ破損時はエラーを表示し、既存データを上書きしません。
同一図面を複数のアプリで同時編集する運用は未対応です。

旧版で手動保存したJSONのインポートUIはありません。
新しい自動保存は本バージョンで開いた図面から開始します。

## エンティティ確認（開発者用）

「表示 → エンティティ確認（開発者用）」で開きます。初期状態は非表示です。

- モデル空間の全エンティティを種類・レイヤで絞り込み
- ハンドル・文字の部分一致検索
- 選択した要素を図面で強調表示し、DXF属性を表示
- 候補あり／なし、描画未対応を区別
- 「検索結果のエンティティだけ図面に表示」で表示対象を限定
- パネルを閉じると全表示へ戻る

検査候補の抽出・採否・CSVにはこの表示フィルタは影響しません。
ブロック内部・ペーパー空間の個別探索は未対応です。
描画未対応の要素は属性のみ確認できます。

## 拡張と制約

CandidateDetectorを追加することで検出方式を拡張できます。
DWGはDXFに変換してから開いてください。
これは完全なCADビューアではありません。文字と実形状、分解された寸法線との
自動対応付けは未実装です。数値文字は要確認候補で、初期状態の採用はオフです。
`2-φ8` などは候補になりますが、旧来の数値抽出は先頭の数を取るため、
数量と直径の分離は未対応です。CSVのvalueは必ず図面と照合してください。

## 検証

自動テスト11件通過。採否・並べ替え・備考編集・CSV・自動保存と再起動復元、
編集中の終了、変更図面、破損データ、保存失敗、開発者用フィルタを検証。
実図面での抽出と表示も検証しています。
GUIはLinuxのオフスクリーン環境で検証。Windows実機の見え方は未確認です。
